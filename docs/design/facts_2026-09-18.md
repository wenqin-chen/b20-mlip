### MACE
- mace-torch 0.3.16 (PyPI 2026-05-10, MIT). Repo github.com/ACEsuit/mace; docs mace-docs.readthedocs.io.
- Checkpoints (github.com/ACEsuit/mace-foundations): MP-0 small/medium/large (MPtrj, MIT; e.g.
  github.com/ACEsuit/mace-mp/releases/download/mace_mp_0/2023-12-03-mace-128-L1_epoch-199.model 44 MB);
  MPA-0 medium (MPtrj+sAlex, MIT; .../mace_mpa_0/mace-mpa-0-medium.model 79 MB; the default since v0.3.10);
  OMAT-0 medium/small (OMat24, ASL academic licence; "most accurate for phonons"); MATPES-PBE/r2SCAN-0 (ASL);
  MH-1 (2025-10-29, ASL, HF mace-foundations/mace-mh-1, arXiv:2510.25380); polar-1 (ASL, arXiv:2602.19411).
  → For an MIT/Apache open repo: fine-tune MPA-0 (or MP-0). Load: mace_mp(model="medium-mpa-0").
- Fine-tuning (docs "experimental"): naive = mace_run_train --foundation_model=... --multiheads_finetuning=False
  --train_file=train.xyz --E0s="estimated" --lr=0.001 --max_num_epochs=6 --energy_weight=10 --forces_weight=10
  --scaling=rms_forces_scaling --ema --amsgrad --default_dtype=float64. Multihead replay: --multiheads_finetuning True
  --pt_train_file mp --num_samples_pt 10000 --subselect_pt fps --weight_pt 1.0 --foundation_model <path>;
  "mp" auto-downloads the MPtrj replay set (MP-0/MPA-0 only); --E0s="foundation"; multihead lr default 1e-4;
  10–30 epochs; replay 10k–30k samples.
- Export: mace_create_lammps_model my.model → my.model-lammps.pt; LAMMPS: pair_style mace no_domain_decomposition;
  pair_coeff * * my.model-lammps.pt <elements>. ASE: mace.calculators.MACECalculator(model_paths=..., device=..., default_dtype=...).
- MPS: float64 on MPS fails (mace-mp issue #14); float32 only → measured unusable for our use; CPU float64 for phonons/relaxations.

### DFT baseline
- PySCF 2.14.0 (Apache-2.0, osx-arm64): k-point KRKS/KUKS/KCCSD with GTH pseudopotentials; PBC stress (GGA), ASE interface for
  lattice/geometry optimisation (2.11), band-structure interface + PBC nuclear gradients (2.13) → finite-displacement
  phonons on small cells are feasible locally (slow for metals with dense k-meshes).

  DFPT "a few minutes"; GaAs 2-atom 80 Ry dense q-mesh "about a day on a quad core".

### Fine-tuning literature (2025–2026)
- Tompa…Csányi arXiv:2606.12704: 7 strategies on OMAT-0/MH-1 with 60–963 configs; naive best for single-system;
  multihead replay "the only approach that consistently preserves out-of-distribution robustness"; LRs: LoRA 1e-2,
  naive 1e-3, multihead ~1e-4; replay 10k MPtrj.
- Radova…Bartók arXiv:2502.15582: frozen transfer learning with 10–20% of the data (hundreds of points) ≈ from-scratch on thousands.
- Liu/Wang/Zhao arXiv:2512.05489: AdamW / ScheduleFree give better curvature conditioning and force accuracy; SGD unstable.
